An iOS app that opens Instagram messages and nothing else. Feed, Explore, profiles, and the Reels tab are sent back to the inbox. Reels and posts sent inside a chat still play.

It is an Expo SDK 54 WebView around https://www.instagram.com/direct/inbox/. You sign in inside the app. There is no Instagram API.

Run it
Install the App Store version of Expo Go (SDK 54), then:


npm install
npx expo start
Scan the QR code with Expo Go.
